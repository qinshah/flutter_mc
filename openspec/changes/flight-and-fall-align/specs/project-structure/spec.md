# Spec Delta

## ADDED Requirements

### Requirement: 物理状态须与判据文件行号绑定

每个运动状态（跳跃、飞行、行走、失焦下落）SHALL 在实现处注明其判据
`文件:行号`；新增状态时 SHALL 同时给出判据。测试 SHALL 覆盖每个状态的**速度**
与**渲染插值连续性**，缺一者视为该状态未对齐。

#### Scenario: 新增状态无判据

- **WHEN** 新增一个影响玩家移动的状态分支
- **THEN** MUST 给出原版判据文件:行号与速度黄金值；指不到即视为未对齐

#### Scenario: 插帧覆盖全部状态

- **WHEN** 某状态的物理按刻递推（20Hz）
- **THEN** 渲染位置 MUST 同样按该状态的刻边界做插值，MUST NOT 只在部分状态插值
