# Spec Delta

## ADDED Requirements

### Requirement: 宿主机制与被托管物分离登记

当某项原版功能以"托管外部原版系 Java 产物"的方式提供（而非在 Dart 侧翻译原版实现）时，
登记 SHALL 分成两部分，缺一不可：

- **宿主机制**（承载方式：进程/嵌入式 JVM、日志管道、生命周期）MAY 标注为第三类自由设计
  "运行时宿主"，并写明平台 API 差异；
- **被托管物**（原版有 Java 实现、本仓未翻译而改为外部运行的部分）SHALL 照旧登记为翻译债，
  条目含原版 `文件:行号`、当前做法（"外部托管"）与判据位置。

MUST NOT 以"该功能已由外部产物提供"为由取消或省略债项。控制面/配置等**原版有实现且本仓
自行实现**的部分不属于被托管物，SHALL 照常逐行翻译，MUST NOT 借"运行时宿主"豁免。

#### Scenario: 托管型功能必须两头都登记

- **WHEN** 新增一个以托管外部 Java 产物方式提供的功能
- **THEN** 既在代码注释中标明宿主机制属于"运行时宿主"，也在 `openspec/progress.md` 登记
  被托管物的债项；只标其一视为登记不完整

#### Scenario: 审查据此校验

- **WHEN** 审查中看到某处标注为"运行时宿主"
- **THEN** 核对被托管物是否已有对应债项；未登记判为违规，处置是补登记或改为翻译原版

#### Scenario: 自行实现的控制面不得挂靠豁免

- **WHEN** 某段控制面/配置读写代码在原版存在对应 Java 实现，且本仓自行编写
- **THEN** 该段 MUST 逐行翻译并给出判据 `文件:行号`，MUST NOT 因同功能另有外部产物而
  援引"运行时宿主"豁免
