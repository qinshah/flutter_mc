# Spec Delta

## MODIFIED Requirements

### Requirement: 多人游戏屏内容

多人游戏屏 SHALL 包含：居中标题"多人游戏"与头部渐变分隔线、**真实服务器列表**（读 servers.dat 兼容存储，条目两行：名称 + 探测状态行——成功为 MOTD/协议号，失败为红字"无法连接至服务器"）、LAN 搜索提示区（文案保留，本期无 LAN 发现）、底部两排按钮（加入服务器 / 直接连接 / 添加服务器；编辑 / 删除 / 刷新 / 返回）。直接连接、添加服务器、刷新、返回 SHALL 始终可用；加入服务器 / 编辑 / 删除 SHALL 在选中条目时可用。删除 SHALL 二次确认。加入服务器的实际连接由 join-and-render 接入（本期点击为占位提示）。

#### Scenario: 示例条目与按钮态

- **WHEN** 首次进入（无 servers.dat）并添加一条服务器后选中
- **THEN** 列表显示该条目；加入服务器/编辑/删除变为可用，其余按钮可用

#### Scenario: 删除二次确认

- **WHEN** 选中条目点"删除"
- **THEN** 出现确认界面，确认后条目移除并持久化
