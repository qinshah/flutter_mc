# client-screens Specification

## Purpose

定义客户端菜单界面的链路与内容契约：主菜单、多人游戏、视频设置三屏按原版 26.2 对应 Screen 的布局要素实现（用户截图为验收参照），本期为视觉与导航骨架——控件可交互、界面可达，不含真实连接与设置持久化。

## Requirements

### Requirement: 菜单页面链路

应用 SHALL 提供三条路由：`/`（标题屏）、`/multiplayer`（多人游戏）、`/settings/video`（视频设置）。标题屏 SHALL 可进入多人游戏与视频设置；多人游戏的"返回"与视频设置的"完成" SHALL 回到标题屏。路由唯一事实来源是 `lib/routes.dart`。

#### Scenario: 冷启动进标题屏

- **WHEN** 应用启动
- **THEN** 首屏为标题屏，出现 MINECRAFT 标题区与主按钮组

#### Scenario: 进入并返回

- **WHEN** 标题屏点"多人游戏"再点"返回"，或点"选项…"进视频设置后点"完成"
- **THEN** 均回到标题屏，无路由残留错误

### Requirement: 标题屏内容

标题屏 SHALL 包含：标题区（MINECRAFT 主标 + JAVA EDITION 副标，本期以文字程序化呈现）、主按钮组（单人游戏、多人游戏、Minecraft Realms、选项…、退出游戏，宽度与间距对照截图）、一组三个方形图标按钮（禁用占位）、右上角倾斜黄色 splash 文本、左下角版本文本（Minecraft 26.2）、右下角版权文本。按钮可用性：多人游戏 / 选项… / 退出游戏可用；单人游戏、Minecraft Realms、图标按钮禁用占位。

#### Scenario: 主按钮组可用性

- **WHEN** 查看标题屏按钮状态
- **THEN** 单人游戏与 Realms 呈禁用态，多人游戏/选项…/退出游戏可点击，退出游戏结束应用

### Requirement: 多人游戏屏内容

多人游戏屏 SHALL 包含：居中标题"多人游戏"与头部渐变分隔线、服务器列表（本期含一条固定示例条目：名称 localhost、状态行"无法连接至服务器"红字、左侧占位图标区、右侧删除叉钮占位）、LAN 搜索提示区（"正在你的本地网络中寻找游戏"）、底部两排按钮（加入服务器 / 直接连接 / 添加服务器；编辑 / 删除 / 刷新 / 返回）。除"返回"外底部按钮本期禁用占位。

#### Scenario: 示例条目与按钮态

- **WHEN** 进入多人游戏屏
- **THEN** 列表显示 localhost 条目（含红色连接失败文案），底部仅"返回"可用

### Requirement: 视频设置屏内容

视频设置屏 SHALL 包含：居中标题"视频设置"、分组标题"显示"与"品质与性能"、以及对照截图的控件清单（全屏分辨率滑条、最大帧率滑条、垂直同步/降低帧率/界面尺寸/全屏/独占全屏/亮度/图形API/预设 的循环或滑条控件，排列与截图一致）、底部"完成"按钮。所有取值仅存于界面内存态，MUST NOT 声称已持久化。

#### Scenario: 控件可交互且不持久化

- **WHEN** 拖动"最大帧率"滑条或循环切换"垂直同步"后点"完成"再重新进入
- **THEN** 交互期间控件与标签实时更新；重新进入后回到默认值（无持久化）
